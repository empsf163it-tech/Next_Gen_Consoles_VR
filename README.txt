PLAYHUB — 6 PAGE GAMING WEBSITE DEMO
=====================================

A responsive static front-end concept combining three broad patterns:
- Steam: game discovery, genre/platform filters, saved games / wishlist behavior.
- IGN: news, reviews and editorial coverage.
- GamesRadar+: guides, features, recommendations and console/VR content.

PAGES
- index.html — Home
- games.html — Discover Games (search, genre/platform filters, local Save wishlist)
- news.html — Gaming News
- reviews.html — Reviews
- guides.html — Guides & Videos
- vr-consoles.html — Consoles & VR

ASSETS
- assets/style.css — responsive styling
- assets/site.js — menu, filtering, local wishlist and demo newsletter behavior
- assets/*.svg — original bundled gaming-themed illustrations

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Use the six-page navigation.

IMPORTANT
- This is a front-end prototype, not a real storefront or live gaming-news aggregator.
- Game names and article content are sample/demo content.
- The wishlist uses browser localStorage on this device only; there is no user account or cloud sync.
- Newsletter and other forms do not send data to a server.
- The design takes inspiration from common gaming store/editorial patterns, but uses original branding, layouts and artwork. It does not copy Steam, IGN or GamesRadar logos, proprietary artwork or exact page designs.
- Before launch, add real game data, licensing, secure APIs/backend, privacy notices, and moderation/security where applicable.
